Agent Desktop — 设置

数据存放位置

此文件夹保存 DSH 主目录：你的 API 密钥、设置与会话历史。 将其复制到另一台 Windows 机器即可全部迁移。

此更改需重启后生效，因为 DSH 在启动时才解析其主目录。

MCP 服务器

配置可供 Agent 调用的外部 Model Context Protocol 服务器 （工具名形如 mcp__<server>__<tool>）。每项对应一个 agent 预设。

更改需重启后生效。

工程目录与查询索引

「项目模式」下项目工具（示例插件 dsh-tool-example）读取的工程根目录， 即 agent 预设中 tool-example 插件的 projectRoot。可以是任意文本/代码工程。

查询索引

预构建的 SQLite 查询索引（工程文本文件的倒排索引），位于工程内的 .agent-index 目录。 AI 查询时不会自动构建索引：缺失或失效（工程文件有改动）时会直接扫描源文件（较慢）并提示你来这里重建。

企业微信归档（可选）

点踩「有问题的回答」时，该轮对话默认打包为 ZIP 保存到本机 <数据文件夹>\feedback-archive。如需改为上传到企业微信微盘， 在 settings.yaml 的 feedback-archive 段设置 backend: wecom， 自行安装 wecom-cli，并在此授权机器人。凭证由 wecom-cli 加密保存在本机 %USERPROFILE%\.config\wecom，本应用不保存也不记录 Secret。
