# Agent Desktop 用户手册

Agent Desktop 是一个 Windows 桌面 AI 助手，内置 DeepSeek Harness：可以读写你选择的工作区、执行命令、调用工具；在「项目模式」下还能对你绑定的工程做快速、可追溯的检索。

---

## 1. 安装与启动

### 1.1 系统要求

- Windows 10 / 11，64 位
- 约 1.5 GB 可用磁盘空间
- 能访问模型服务（默认 DeepSeek 官方 API）

### 1.2 免安装版（推荐）

1. 把收到的压缩包解压到任意目录（例如 `D:\Apps\`）。**建议路径只含英文字母、数字**。
2. 打开 `Agent Desktop\` 文件夹，双击 `Agent Desktop.exe`。
3. 首次运行如果出现 Windows SmartScreen「已保护你的电脑」：点「更多信息」→「仍要运行」（程序未做代码签名）。

可以给 `Agent Desktop.exe` 创建桌面快捷方式。

### 1.3 安装包版（如有）

运行 `Agent Desktop Setup <版本>.exe`，按向导安装，之后从开始菜单启动。

### 1.4 升级

1. 托盘图标右键 → Quit（或在主窗口按 `Ctrl+Q`）完全退出。
2. 用新版本的程序文件夹整体替换旧文件夹。
3. 你的配置、会话、API Key 不在程序文件夹里（见 §3），升级不受影响。
   如果你使用的是「随程序便携」模式，替换时请保留旧文件夹中的 `dsh-data\` 和 `desktop-shell.json`。

### 1.5 窗口与托盘

- 点窗口右上角 **X 只是隐藏到托盘**，正在进行的任务不会中断。双击托盘图标重新打开。
- 真正退出：托盘右键 → Quit，或 `Ctrl+Q`。
- 程序只允许运行一个实例；再次双击 exe 会唤起已有窗口。

### 1.6 快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl+,` | 打开 Agent Desktop 设置窗口 |
| `Alt` | 显示菜单栏 |
| `Ctrl+R` / `Ctrl+Shift+R` | 重新加载界面 / 强制重新加载 |
| `Ctrl+0` / `Ctrl+=` / `Ctrl+-` | 重置 / 放大 / 缩小 |
| `F11` | 全屏 |
| `Ctrl+Shift+I` | 开发者工具（排障用） |
| `Ctrl+Q` | 退出程序 |

## 2. 首次启动：填写 API Key

首次启动会弹出引导窗口，要求填写 **DeepSeek API Key**（`DEEPSEEK_API_KEY`）。

1. 在 DeepSeek 开放平台申请自己的 API Key（请使用你本人的 Key，不要共用）。
2. 粘贴到输入框，确认。
3. 默认模型为 `deepseek-v4-pro`。

之后要修改 Key 或模型：主窗口 → 设置 → 模型。Key 保存在数据根下的 `.credentials.yaml`，**请勿把这个文件发给他人**。

> 如果你的团队使用其它兼容 OpenAI 接口的模型网关，请按管理员提供的说明在 设置 → 模型 中添加。

---

## 3. 数据保存在哪里

所有配置、会话、密钥都在一个「数据根」文件夹里。默认位置：

```
%APPDATA%\Agent Desktop\dsh-home
```

（在资源管理器地址栏输入 `%APPDATA%\Agent Desktop` 即可打开。）

在 设置窗口（`Ctrl+,`）→「数据存放位置」可以切换：

| 选项 | 位置 | 适用 |
|---|---|---|
| 用户目录（默认） | `%APPDATA%\Agent Desktop\dsh-home` | 一般使用 |
| 随程序便携 | 程序目录下的 `dsh-data\dsh-home` | 放在 U 盘、整个文件夹拷到别的电脑 |
| 自定义 | 任意文件夹 | 放在同步盘等 |

切换后点「应用」，**重启生效**。可选择把现有数据一起迁移过去。「打开数据文件夹」按钮直接在资源管理器中打开当前数据根。

数据根中的主要内容：

| 文件 / 目录 | 内容 |
|---|---|
| `settings.yaml` | 全部设置（模型、语言、默认模式、点踩归档等） |
| `.credentials.yaml` | API Key 等密钥 |
| `.agent-presets\project\` | 项目模式的配置 |
| `sessions\` | 会话历史 |
| `feedback-archive\` | 点踩归档（本地后端） |

## 4. 开始对话

1. 主窗口中「选择工作区目录」：选择一个文件夹，Agent 将在其中读写文件、执行命令。目录选择使用程序内置的浏览对话框。
2. 选择模式（预设）：
   - **标准**：通用编码 / 办公 Agent；
   - **项目模式**：在标准能力之上，增加对已绑定工程的检索工具和可选的知识库查询（见 §5）；
   - 其它 DSH 自带模式。
3. 输入问题。Agent 执行有风险的操作（写文件、运行命令）前可能会请求确认。
4. Agent 生成的报告文件会以文件卡片形式出现在回答中，点击即可打开。

## 5. 项目模式与工程目录

项目模式让 Agent 用专用工具在你的工程里检索，而不是一个个文件地翻找。回答会附带 `文件:行号` 形式的证据，便于核对。

### 5.1 绑定工程目录

1. `Ctrl+,` 打开设置 →「工程目录与查询索引」。
2. 点「浏览…」选择工程根目录（或直接粘贴路径），点「保存」。
3. 按提示**重启程序**。

未绑定时，项目模式的检索工具会提示你先绑定。

### 5.2 重建查询索引

为了让检索更快，程序可以为工程建立查询索引（保存在工程目录下的 `.agent-index\` 文件夹）。

1. 同一页点「检查索引」查看状态（未建立 / 已就绪 / 已过期 / 正在建立）。
2. 点「重建索引」。进度窗口显示当前进度，可随时「取消重建」——取消不会破坏已有索引。
3. 完成后关闭进度窗口即可，无需重启。

说明：

- **没有索引也能用**，只是慢一些；这时回答末尾会提示你到设置里重建索引。
- 工程文件改动较多后，索引会被判定为过期，同样会提示重建。
- 重建期间可以继续使用程序。
- 如果你的工程使用版本控制，建议把 `.agent-index/` 加入忽略列表。

### 5.3 知识库（可选）

若团队提供了知识库 MCP 服务，项目模式在本地工程查不到答案时会自动转去知识库查询。开启方法见 §6；首次使用会弹出浏览器登录。知识库查询可能需要较长时间，若返回查询编号，Agent 会告诉你编号，稍后可凭编号追问结果。

## 6. MCP 服务器配置

设置窗口 →「MCP 服务器」可以为某个模式管理 MCP 工具服务：

- **添加服务器**：填写名称、类型（HTTP 地址，或本地命令 stdio）与参数；
- **测试**：检查 HTTP 类型服务能否连通、列出工具；
- **启用 / 禁用 / 编辑 / 删除**已有服务器；
- 修改后**重启生效**。

项目模式预置了一个名为 `knowledge` 的知识库服务条目，**默认禁用**。启用步骤：

1. 安装 [Node.js](https://nodejs.org)（LTS 版本），然后在命令行执行 `npm i -g mcp-remote`。
2. 在「MCP 服务器」中编辑 `knowledge`：把示例地址 `https://kb.example.com/mcp` 改为团队提供的地址，并启用。
3. 重启程序。首次调用时浏览器会弹出登录页，登录令牌保存在 `%USERPROFILE%\.mcp-auth\`。

> 如果安装 Node / mcp-remote 是在首次启动之后进行的，而 `knowledge` 仍无法启动，可以删除 `<数据根>\.agent-presets\project\` 文件夹后重启，让程序按本机环境重新生成项目模式配置（会清除你对该模式的自定义，需要重新绑定工程目录）。

---

## 7. 点踩归档

对不满意的回答点 👎、选择分类并写下原因，这一轮完整对话就会被打包保存，便于后续改进。

- 默认保存到本机：`<数据根>\feedback-archive\<模式>\<日期>\`；
- 也可以配置为上传到企业微信微盘。

详见随附文档 [`feedback-archive.md`](feedback-archive.md)。

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| 界面显示 "Failed to load plugins" | 完全退出（`Ctrl+Q`）后重新打开；程序启动时会清理导致该问题的过期 Cookie |
| 选择工作区后一直停在"选择一个工作区开始" | 重启程序（启动时会自动修复默认模式配置）；仍不行请在主窗口设置中重新选择默认模式 |
| 选择目录的对话框没有反应 | 确认使用的是最新版本；重启程序 |
| 项目模式提示没有绑定工程目录 | 见 §5.1，保存后需重启 |
| 回答很慢，末尾提示去设置里重建索引 | 见 §5.2 |
| 重建索引提示"已有重建在进行" | 等当前重建完成或先取消；若程序异常退出过，重启后即可 |
| 知识库工具不出现 | 见 §6，确认已启用并重启 |
| 知识库要求重新登录 | 删除 `%USERPROFILE%\.mcp-auth\` 后重启 |
| 设置窗口某个卡片一直转圈 | 程序更新后未完全退出，`Ctrl+Q` 后重新打开 |
| 程序放在中文路径下无法启动 | 把程序文件夹移动到只含英文字母和数字的路径 |
| 手工编辑 `settings.yaml` 后程序无法启动 / 中文乱码 | 用支持 UTF-8 的编辑器（如 VS Code、记事本另存为 UTF-8）编辑；不要用 Windows PowerShell 5 的 `Get-Content | Set-Content` 改写中文 YAML |
| 需要查看端口、版本、数据位置 | 设置窗口 →「诊断信息」 |

### 反馈问题时请提供

- 设置窗口「诊断信息」中的内容（版本、数据根、端口）；
- 程序没有单独的日志文件。需要启动日志时，在 PowerShell 中进入程序目录运行 `& ".\Agent Desktop.exe"`，把窗口中 `[dsh-desktop]` 开头的输出一并提供；
- 界面错误：按 `Ctrl+Shift+I` 打开开发者工具，截图 Console 中的红色报错。
